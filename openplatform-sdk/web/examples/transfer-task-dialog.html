Transfer Task Detail Dialog

用于展示转账任务详情的弹出对话框组件。

支持单笔/多笔转账模式，展示任务状态、交易详情、Travel Rule 等信息。

任务状态

Pending / Wait for Sign / Approved / Rejected

多笔模式

支持单笔和多笔收款人模式切换

Travel Rule

展示发件人和收件人合规信息

使用示例

import { openTransferTaskDetailDialog } from '@cregis/openplatform-sdk';

const dialog = openTransferTaskDetailDialog({
  taskId: '#TRX-8829',
  status: 'wait_for_sign',
  amount: '10,000.00',
  coin: 'USDT',
  network: 'Ethereum',
  from: { name: 'Alice Corp', address: '0x1234...' },
  to: { name: 'Bob Inc', address: '0xabcd...' },
  meta: { unit: 'Main', createdAt: '2026-04-10', expiresIn: '2h 30m' },
  approvalFlow: [
    { name: 'Initiated', status: 'completed' },
    { name: 'Approval', status: 'current' },
    { name: 'Execution', status: 'pending' }
  ]
}, {
  title: 'Review Transfer',
  onClose: () => console.log('Dialog closed')
});
